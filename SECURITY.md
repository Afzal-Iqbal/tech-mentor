# Security Policy

## Reporting Security Issues
We take security and user privacy seriously. TechSaathi AI handles educational and simulation content for digital literacy.

If you discover a security vulnerability or accidental exposure of secrets/keys, please **do not open a public issue**. Instead, report it directly to:
- Syed Muhammad Hunain ([hunainsince2005@gmail.com](mailto:hunainsince2005@gmail.com))

We will acknowledge your report within 48 hours and work on a prompt resolution.

## Security Guarantees & Constraints
- **Zero Real Banking Data**: TechSaathi AI never asks for or stores real banking credentials, ATM PINs, OTPs, CVVs, or account passwords.
- **Simulated Environment**: All financial transaction flows are purely simulated and self-contained.
- **Ephemeral AI Processing**: Screenshot images submitted for explanation are processed ephemerally and must not be retained in public cloud databases.
- **No Hardcoded Keys**: API keys and secrets must never be committed to source control; use environment variables or secure remote configuration.
